# 🛒 Modern Food Store

::: {align="center"}
A modern **React** e-commerce frontend built with **Vite**, **Tailwind
CSS**, and **Framer Motion**.

**🌐 Live Demo:**
https://salarkarimibag-cmd.github.io/modern-food-store/
:::

------------------------------------------------------------------------

## 📖 About

Modern Food Store is a responsive frontend shopping application focused
on clean architecture, reusable React components, modern UI, smooth
animations, and an enjoyable shopping experience.

### Highlights

-   🛍️ Product listing
-   🔎 Category filtering
-   🛒 Shopping cart
-   🌙 Dark / Light mode
-   📱 Responsive design
-   ✨ Glassmorphism UI
-   🎞️ Framer Motion animations
-   ⚡ Built with Vite

------------------------------------------------------------------------

# 🚀 Installation

``` bash
git clone https://github.com/salarkarimibag-cmd/product-category-filter.git
cd product-category-filter
npm install
npm run dev
```

------------------------------------------------------------------------

# 📦 Production

``` bash
npm run build
npm run preview
```

Deploy:

``` bash
npm run deploy
```
